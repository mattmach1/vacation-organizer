# Vacation Organizer
The purpose of this application is to allow users to save vacations with detailed information. Users are able to add excursions to vacations as well as share the vacation details with friends.

# How to use the application

## Vacations
To add a new vacation, click on the plus icon on the Vacation List page. After the information has been entered, click the menu icon in the top right corner and select "Save".  
To edit a vacation, navigate to the Vacation Details page and click the field you would like to edit.  
To delete a vacation, navigate to the Vacation Details page, select the menu icon in the top right of the screen and click "Delete".  
You will not be able to delete a vacation if there is an excursion associated with it. you must first delete the excursion, then delete the vacation.  
To share a vacation, navigate to the Vacation Details page, select the menu icon in the top right of the screen and click "Share".  
To set an alert for a vacation, navigate to the Vacation Details page, select the menu icon in the top right of the screen and click "Set Alert".

## Excursions
To add a new excursion, click on "View Excursions" on the Vacation Details page. Then click the plus icon on the Excursion List page.  
To edit an excursion, navigate to the Excursion Details page and click the field you would like to edit.  
To delete an excursion, navigate to the Excursion Details page. Then click on the menu icon in the top right and select "Delete".  
To set an alert for an Excursion, navigate to the Excursion Details page. Then select the menu icon in the top right and click, "Set Alert".
